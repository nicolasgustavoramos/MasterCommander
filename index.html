Características Principales

🚀 Diagnóstico Rápido

Visor de hardware completo, test de velocidad de red, estado de la batería y monitor de ping en tiempo real.

🧹 Limpieza Profunda

Elimina archivos temporales, cachés de navegadores (Chrome, Edge, Firefox), miniaturas y vacía la papelera de forma segura.

⚙️ Gestores Avanzados

Control total sobre procesos, servicios de Windows, tareas de inicio, puertos TCP abiertos y desinstalación de programas.

🛡️ Red y Seguridad

Configuración de DNS, auditoría del Firewall de Windows, actualizaciones del sistema y análisis de inicio.

💾 Sistema Avanzado

Desfragmentación (HDD/SSD), reparación de archivos del sistema con SFC y DISM, puntos de restauración y backup del registro.

📊 Widget Flotante (HUD)

Monitorización en tiempo real de CPU, RAM, Red, Temperatura y Batería con una interfaz flotante no intrusiva.

Instalación y Requisitos

Requisitos Mínimos

  • Windows 10 (v1607) o Windows 11
  • .NET 9 Desktop Runtime
  • 50 MB de espacio libre en disco
  • Permisos de Administrador (UAC)

Pasos para Instalar

  1. Haz clic en el botón de Descargar.
  2. Ejecuta el archivo MasterCommander_Setup.exe.
  3. Acepta los términos y condiciones legales.
  4. Selecciona la instalación (Completa o Básica).
  5. ¡Listo! El programa se abrirá automáticamente.
⚠️ Nota sobre Windows SmartScreen Master Commander es un proyecto independiente. Al no contar con un certificado de firma comercial (EV) de pago, es posible que Windows SmartScreen muestre una advertencia de seguridad. Para instalar de forma segura, haz clic en "Más información" y luego en "Ejecutar de todos modos". El código es 100% seguro y de código abierto.
